# 秋招活动日历 · 2026 秋招季

北京高校（北理工 / 清华 / 北大 / 北航 / 人大 / 北师大 / 农大 / 民大 / 北工大）2027 届秋季双选会、宣讲会的可交互日历看板。

面向：北理工材料学院能源与环境材料系硕士 · 2027 届 · 目标＝央企国企双碳岗 + 北京体制内 · 城市仅北京。

## 功能

| 功能 | 说明 |
|---|---|
| 周日历视图 | 9/7 起共 7 周，七列排布，自动定位到今天所在周 |
| 悬停展开 | 鼠标移到卡片上展开建议信息 + **来源链接**（可直接点开核实） |
| 点击详情 | 点卡片弹出完整信息：时间 / 地点 / 分类 / 建议 / 来源原文链接 |
| 叉掉 | 卡片右上角 `×`，不去的场次直接划掉，自动保存到本机 |
| **撤销** | 顶部「↩ 撤销」按钮或 **Ctrl+Z**，支持连续多步回退 |
| **回收站** | 列出所有已叉掉的场次，可单独恢复；「全部恢复」一键还原 |
| 筛选 | 全部 / 必去+优先 / 北理工 / 清华北大北航 / 全市开放 |
| 四级配色 | 深绿＝必去，橙＝优先，浅绿＝可去，灰＝可弃；红色「重磅」标关键场次 |

数据保存在浏览器 localStorage，换设备或清缓存会重置。

## 更新数据

**只改 `events.js` 就行，`index.html` 不用动。**

每行格式：

```js
[日期, 时间, 单位/活动, 地点, 级别, 类型, 备注, 重磅?, 来源key, 精确URL?]
```

- 日期：`"09-07"` 格式
- 级别：`1`=必去 `2`=优先 `3`=可去 `4`=可弃
- 类型：`bit` 北理工 / `thu` 清华 / `pku` 北大 / `buaa` 北航 / `other` 其他校 / `city` 全市开放
- 重磅：填 `1` 显示红色「重磅」标，否则填 `0`
- 来源key：见 `events.js` 顶部的 `SRC` 表（bit / buaawx / thu / pku / city / muc / bjut / bnu / cau / ruc）
- 精确URL：可选，填了就优先用它作为该条的来源链接

新增来源站点：在 `SRC` 里加一条；纯参考性质的页面加到 `REFS`。

改完后更新顶部的 `DATA_VERSION`，规则：**V{月}.{日}.{当日第几次更新}**，如 9 月 7 日第 2 次更新 = `V9.7.2`，次日第 1 次 = `V9.8.1`。同时在 `CHANGELOG` 里加同名 key（弹窗内容：title + items + cheer），新版本会在访客端自动弹一次。

页面底部有随机鼓励语（`index.html` 的 `QUOTES` 数组），每次打开换一句，想增删句子直接改数组。

## 免责提醒

- 各校双选会入场资格**未经电话确认**，出行前务必先向举办方核实。
- 清北部分双选会官方写明面向本校学生；宣讲会现场通常可旁听。
- 前往外校请带身份证，按校方入校规定报备。
- 京彩就业场次的时间与展位名单以 bjbys 官网公布为准。
- 招聘活动可能因实际情况调整或取消，以学校就业平台及用人单位最新通知为准。
